# HealthConnect Clinic – Data Analytics

## Project Overview
HealthConnect Clinic is a fictional healthcare provider experiencing
challenges with missed appointments and inefficient use of appointment slots.

## Objective
The goal was to understand the appointment dataset,
assess its quality, define relevant business questions and KPIs,
and develop an initial analysis approach.

## Dataset
The dataset contains 5,000 appointment records and 18 variables.

## Data Quality Findings
- 5,000 records
- 18 variables
- No duplicate appointment IDs
- 90 missing distance values
- 60 missing waiting-time values
- Date-format discrepancy identified between the CSV and Data Dictionary

## Business Questions
1. What proportion of appointments result in no-shows?
2. How does waiting time relate to no-show behaviour?
3. Are reminders associated with better attendance?
4. Are previous no-shows associated with future no-shows?
5. Does distance from the clinic relate to attendance?

## Proposed KPIs
- Appointment No-Show Rate
- No-Show Rate by Waiting-Time Group
- No-Show Rate by Reminder Status
- Repeat No-Show Rate
- No-Show Rate by Distance Group
